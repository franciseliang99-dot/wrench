# Corpus

Everything here is written for this project and is **fictional**:

- `manual/`: service manual for the WD-200, an invented air compressor. Sections are numbered `M-<chapter>.<section>`.
- `logs/maintenance.jsonl`: 30 synthetic maintenance records for invented units `C-01` … `C-06`
  (`C-01` is the label this project gives to the single compressor in the MetroPT-3 data).

No real company, product, person or part number appears. Released under the repository's MIT license.
